# Caso de prueba — TC-01: Login y bloqueo por intentos fallidos

- **ID:** TC-01
- **Historia relacionada:** HU-01
- **Feature / pantalla:** Login (`/login`)
- **Plataforma(s):** Android (emulador)
- **Tipo:** Sesión

---

## Precondiciones

- API en ejecución con el seed cargado (`admin@activogo.co` / `Activo2026!`).
- App instalada y sin sesión iniciada.

---

## Pasos

| # | Acción | Resultado esperado |
|---|--------|--------------------|
| 1 | Escribir `admin@activogo.co` y la contraseña correcta, tocar iniciar sesión. | Se entra a `/activos` y la barra muestra el rol ADMIN. |
| 2 | Cerrar sesión; escribir el correo con una contraseña incorrecta. | Se muestra "Usuario o contraseña incorrectos" y se permanece en `/login`. |
| 3 | Repetir la contraseña incorrecta hasta completar 3 intentos. | Se muestra "Cuenta bloqueada temporalmente, intenta más tarde" (la API responde 423). |
| 4 | Intentar entrar con la contraseña correcta mientras dura el bloqueo. | El acceso sigue rechazado hasta que termine el bloqueo. |
