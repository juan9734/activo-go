# Accesibilidad

> Cómo se garantiza que la app sea accesible.

- [ ] Todo elemento interactivo tiene etiqueta accesible (`aria-label` en botones de solo ícono).
- [ ] Áreas táctiles de al menos 44×44 pt (iOS) / 48×48 dp (Android).
- [ ] El texto escala con el tamaño de fuente del sistema (`rem`, sin tamaños fijos en el cuerpo).
- [ ] Contraste WCAG AA (4,5:1 en texto normal).
- [ ] Orden de foco y navegación por teclado/lector de pantalla verificados en pantallas clave.

> Checklist por pantalla en [_plantilla-pantalla.md](../01-arquitectura/_plantilla-pantalla.md).
